# LESSON-5 — useRef и работа с DOM

Ветка: `lesson-5`. База PR: `main`. Приложение находится в `lesson-5/`.

## Что сделано

- **ClickTimer:** время первого клика и общий счётчик хранятся в типизированном ref. Каждый клик выводит в консоль количество нажатий и время от первого клика в секундах.
- **PreviousInput:** текущее значение поля хранится в state, предыдущее — в ref. Эффект сначала выводит сохранённый текст через DOM-ref, затем запоминает текущее значение. Предыдущее значение не хранится в state, чтения ref во время рендера нет.
- **FocusTracker:** два DOM-ref позволяют управлять фокусом. Кнопка фокусирует первое поле. Обработчик `onFocus` сравнивает `relatedTarget` с другим полем и увеличивает счётчик в ref только при прямом переходе между полями. Начальный фокус и переход с кнопки не учитываются.
- **DebouncedLogger:** таймер хранится в ref и перезапускается при каждом вводе. Текст выводится в консоль через секунду после последнего изменения. Таймер очищается при размонтировании; состояние для текста не используется.
- **WebSocketLogger:** соединение с `wss://echo.websocket.org` создаётся в `useEffect` и хранится в ref. После открытия отправляется тестовое сообщение, входящие сообщения выводятся в консоль. Cleanup закрывает созданное соединение.

Обновление ref само по себе не вызывает ререндер. `useState` используется только
в `PreviousInput` для текущего текста. Все компоненты подключены на одной странице
и оформлены в едином адаптивном стиле.

## Запуск и проверки

Node.js: `^20.19.0 || ^22.13.0 || >=24` — с учётом требований ESLint 10.
В `.nvmrc` указана ветка 22.

Из корня репозитория:

```sh
cd lesson-5
nvm use
npm ci
npm run dev
```

Откройте адрес Vite и консоль браузера. Для WebSocket нужен доступ к внешнему
сервису `echo.websocket.org`. В режиме разработки `StrictMode` может выполнить
дополнительный цикл подключения и очистки соединения.

Из папки `lesson-5`:

```sh
npm run check
```

Команда выполняет проверку TypeScript, сборку Vite, ESLint без предупреждений
и проверку форматирования Prettier. Для исправления форматирования:

```sh
npm run format
```

### Проверка поведения

- Несколько кликов: счётчик растёт, время отсчитывается от первого нажатия.
- Ввод `А`, затем `АБ`: предыдущее значение меняется с пустой строки на `А`.
- Переходы между полями: счётчик увеличивается; кнопка возвращает фокус в первое поле.
- Быстрый ввод: в консоли появляется только последнее значение после паузы в секунду.
- WebSocket: после открытия соединения в консоли появляется ответ на тестовое сообщение.
