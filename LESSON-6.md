# LESSON-6 — Авторизация и защищённые маршруты

Ветка: `lesson-6`. База PR: `main`. Приложение находится в `lesson-6/`.

## Что сделано

### Контекст и защита маршрутов

`AuthProvider` хранит данные авторизации и имя пользователя в контексте.
Хук `useAuth` читает контекст через `useContext` и сообщает об ошибке,
если используется вне провайдера.

`ProtectedRoute` проверяет токен из контекста. При его отсутствии выполняется
`Navigate` на `/login` с `replace`, при наличии отображаются вложенные маршруты
через `Outlet`. При запуске провайдер восстанавливает токен из `localStorage`.

### Вход

`LoginPage` содержит обязательные поля email и password. Форма отправляет
асинхронный POST-запрос на `https://api.v2.react-learning.ru/auth/login`.
После успешного ответа токен сохраняется в `localStorage`, контекст обновляется,
а пользователь переходит на `/profile` с заменой записи истории.
Во время запроса кнопка заблокирована; ошибка отображается в форме.

Используется рабочий адрес API без префикса `/api`, подтверждённый запросом
входа на учебном демо-сайте.

### Профиль

`ProfilePage` находится внутри защищённого маршрута. Страница запрашивает
`https://api.v2.react-learning.ru/users/me`, передавая токен в заголовке
`Authorization`. Полученное имя сохраняется в контексте и отображается
в заголовке. При F5 токен восстанавливается, данные профиля запрашиваются заново.
Предусмотрены состояния загрузки и ошибки. Кнопка выхода доступна и в этих состояниях.

### Бонус: публичная страница и выход

`/public` доступен без авторизации. Кнопка «Выйти» размещена на странице профиля:
она удаляет токен из `localStorage`, очищает контекст и переводит на `/login`
через `navigate` с `replace`. После выхода `ProtectedRoute` закрывает доступ
к `/profile`.

## Запуск и проверки

Окружение Node.js: `^20.19.0 || ^22.13.0 || >=24` (с учётом ESLint 10).
В `.nvmrc` указана ветка 22.
Из корня репозитория:

```sh
cd lesson-6
nvm use
npm ci
npm run dev
```

Откройте `/login` по адресу, выведенному Vite. Для входа нужен зарегистрированный
учебный аккаунт и доступ к API. Регистрация в приложении не реализуется.

| Маршрут                       | Назначение             |
| ----------------------------- | ---------------------- |
| `/login`                      | Вход                   |
| `/profile`                    | Защищённый профиль     |
| `/public`                     | Общедоступная страница |
| Остальные адреса, включая `/` | Страница не найдена    |

Проверки из папки `lesson-6`:

```sh
npm run build
npm run lint
```

Сборка и ESLint прошли. В Safari проверены успешный вход, переход на `/profile`,
сохранение доступа после F5 и отображение имени пользователя.

Для проверки выхода: нажать «Выйти», убедиться в переходе на `/login`,
затем открыть `/profile` вручную — должен произойти редирект обратно на `/login`.
Страница `/public` должна оставаться доступной без токена.
