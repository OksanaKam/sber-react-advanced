# LESSON-4 — Формы и валидация

Ветка: `lesson-4`. База PR: `main`. Приложение находится в `lesson-4/`.
Менеджер задач первых трёх уроков перенесён в `lesson-1-3/`.

## Что сделано

### Форма регистрации и схема валидации

Форма реализована на React Hook Form. Поля `username`, `email`, `password`
и `confirmPassword` обязательны. Проверяются формат email, длина пароля
от 6 символов и совпадение паролей. Ошибки отображаются рядом с полями,
невалидные поля выделяются красной рамкой.

**Схема Zod использована сразу на шаге 1 и подключена через `zodResolver`.
Таким образом, требование шага 2 выполнено без промежуточной ручной валидации.**
См. [схему валидации](lesson-4/src/features/react-hook-form/model/formSchema.ts)
и [подключение к форме](lesson-4/src/features/react-hook-form/ui/ReactHookForm.tsx).

Тип значений формы получен из схемы через `z.infer`. При успешной отправке
данные показываются в `alert`; запрос регистрации на сервер не выполняется.

### Динамические социальные ссылки

Список профилей реализован через `useFieldArray`. По умолчанию отображается
одна строка с названием платформы и ссылкой. Можно добавлять новые строки
и удалять любые существующие, включая последнюю. Для ключей используется
стабильный `field.id`.

Название платформы обязательно, ссылка проверяется как URL в схеме Zod.
Ошибки выводятся рядом с соответствующим полем массива. На широком экране
поля и кнопка удаления расположены в строку, на узком — в столбец.

### Бонус: двухшаговая подписка через useActionState

Отдельная форма использует `useActionState` из React 19. На первом шаге
проверяется email, на втором пользователь подтверждает подписку или
возвращается к редактированию адреса.

Во время выполнения действия отображаются «Отправляем…» и статус обработки,
кнопки блокируются. Пустой или некорректный email сопровождается ошибкой,
успешное подтверждение — сообщением в интерфейсе. Отправка имитируется
асинхронной задержкой в одну секунду; реальная подписка не оформляется.

## Запуск и проверки

Node.js: `^20.19.0 || >=22.12.0`; `.nvmrc` выбирает ветку 22.
Из корня репозитория:

```sh
cd lesson-4
nvm use
npm ci
npm run dev
```

Откройте адрес, выведенный Vite. Обе формы расположены на главной странице.

Проверки из папки `lesson-4`:

```sh
npm run build
npm run lint
npm run format:check
```

Общая команда: `npm run check`. Форматирование: `npm run format`.

Сборка TypeScript и Vite, а также линтер ESLint проходят успешно.
Проверены пустые и корректные значения, несовпадение паролей, некорректный
URL, пустой список ссылок и переходы между шагами подписки.
