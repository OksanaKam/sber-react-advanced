## Сущность Task

- Добавлен интерфейс `Task`: `id`, `title`, `completed`.
- `TaskCard` получает задачу через props и отображает заголовок и статус.
  Компонент не содержит состояния, эффектов или действий с задачами.
- Стили находятся рядом в `TaskCard.module.css`. Статус обозначен текстом,
  значком и цветом.
- Тип и компонент экспортируются через публичный `entities/task/index.ts`.
- На странице показаны три начальные задачи с разными статусами.

## Список задач

- `features/taskList/model/useTasks.ts` хранит полный список и текущий фильтр
  в `useState`, возвращает отфильтрованные задачи и обработчики.
- Удаление по ID изменяет полный список через функциональное обновление состояния.
  Фильтрация не изменяет исходные данные.
- `TaskList` получает начальные задачи через props, выводит `TaskCard`,
  три фильтра и кнопки удаления. Пустые результаты сопровождаются сообщением.
- Фильтры имеют `aria-pressed`, кнопки удаления — доступные названия с заголовком задачи.
- Импорты сущности идут через публичный `entities/task`, согласно правилам FSD.
- Данные хранятся в памяти: после перезагрузки страницы восстанавливаются примеры.
- `npm run check` прошла: сборка, ESLint и Prettier. Интерактивная проверка
  в браузере в этой сессии не выполнялась.

### Ручная проверка

1. «Все»: видны все три начальные задачи.
2. «Выполненные» и «Невыполненные»: видны только задачи нужного статуса.
3. Удалите задачу при активном фильтре, затем выберите «Все»: она не возвращается.
4. Удалите все оставшиеся задачи: появляется сообщение «Задач пока нет».
5. Перезагрузите страницу: начальные задачи снова отображаются.

## Страница и виджет

- `pages/tasks/ui/TaskPage.tsx` выводит заголовок и `TaskWidget`.
- Виджет экспортируется через публичный `widgets/task/index.ts`.
- `TaskWidget` содержит начальные данные и подключает `TaskList`. Состояние, фильтрация и удаление остаются в feature,
  без дублирования логики в виджете или странице.
- Цепочка компонентов: TaskPage → TaskWidget → TaskList → TaskCard.

## Дополнительная задача

Компонент `shared/ui/FilterButton` подключён в `TaskList`. Он получает
`active`, `onClick` и `children`, сохраняет `aria-pressed` и стили в CSS-модуле.
Компонент не зависит от типов задач или фильтров слоя features.
