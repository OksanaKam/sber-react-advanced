# React Advanced — учебные проекты

Один репозиторий для домашних заданий курса SberUniversity.

- `main` — общая основа курса.
- `lesson-N` — отдельная ветка от `main` для урока N.
- `final` — итоговый проект.
- Для каждого урока создаётся один pull request в `main`.

Проект урока находится в папке `lesson-N/`, описание и чек-лист —
в файле `LESSON-N.md` в корне репозитория соответствующей ветки.

Команды выполняются из папки нужного урока:

```sh
cd lesson-N
npm ci
npm run dev
```

Перед сдачей: `npm run build` и `npm run lint`.
Зависимости, секреты и результаты сборки в Git не добавляются.
